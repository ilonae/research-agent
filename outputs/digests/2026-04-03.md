# ArXiv Digest — 2026-04-03

## 1. Concept-based Explanations for Graph Neural Networks via Hierarchical Prototype Learning

**Keywords matched:** explainab, prototype, interpretab

This work introduces a hierarchical prototype learning framework for GNNs that aligns graph substructures with human-interpretable concepts, enabling faithful post-hoc explanations without sacrificing model accuracy. By grounding explanations in learned prototypes rather than gradient attribution, the method bridges the gap between local saliency maps and global semantic understanding.

https://arxiv.org/abs/2404.00001

## 2. SHAP-Guided Pruning: Efficient Neural Network Compression via Attribution Scores

**Keywords matched:** SHAP, pruning, interpretab

The authors propose using SHAP values as a principled criterion for structured pruning, removing neurons whose average contribution across the training distribution falls below a learned threshold. On standard vision benchmarks the method matches magnitude-based pruning on accuracy while producing sparser, more interpretable networks.

https://arxiv.org/abs/2404.00002

## 3. Layer-wise Relevance Propagation for 3D Point Cloud Classification

**Keywords matched:** LRP, point cloud, attribution

This paper extends LRP to PointNet-style architectures, deriving propagation rules that respect the permutation-invariant aggregation steps central to point cloud processing. Visualisations on ModelNet40 reveal that the model correctly attends to geometric edges and surface normals, providing the first quantitative faithfulness evaluation for point cloud XAI.

https://arxiv.org/abs/2404.00003
